# Image assets — The Green Frog Café

The website references the filenames below. **Drop your photos into this `assets/`
folder using these exact names** and they'll appear automatically.

Until a file is added, the site shows a tasteful stock fallback, so nothing
ever looks broken. To swap a photo later, just overwrite the file (same name).

| Filename                | Use on site                  | Which photo you sent                                   |
|-------------------------|------------------------------|--------------------------------------------------------|
| `hero-smoothies.jpg`    | Big hero background          | The two smoothies (pink + green) on the green table    |
| `coffee-latte.jpg`      | About section + gallery      | The close-up latte art coffee                          |
| `interior-sign.jpg`     | About section                | The "GREEN FROG CAFE — WESTERN ROAD" wall + booth      |
| `storefront.jpg`        | Gallery (wide)               | The exterior shopfront with the frog logo              |
| `sandwich.jpg`          | Gallery                      | The roast beef baguette with side salad                |
| `mascot-plush.jpg`      | Gallery                      | The plush frog holding the eco cup                     |
| `interior-counter.jpg`  | Gallery                      | The counter with the cake/pastry display               |
| `counter-plants.jpg`    | Gallery                      | The wooden counter with the tall dracaena plant        |

### Recommended sizes
- `hero-smoothies.jpg` — landscape, ~1600px wide, < 400KB (this one loads first).
- Everything else — ~900–1200px on the long edge, < 250KB each.
- Use `.jpg` for photos. Keep the names lowercase exactly as above.

## Logo

`logo.svg` is a faithful **recreation** of the frog-with-glasses mark, drawn as
scalable vector so it stays razor-sharp at any size and on retina screens.
If you have the official logo file (SVG or transparent PNG), replace `logo.svg`
with it (keep the name `logo.svg`, or update the `<img src>` references in
`index.html` if you use a `.png`).
